# Android 2.0.3 — Dark mode

Open More → Appearance and choose System, Light, or Dark. The default is System. Your choice is saved on the phone. Changing appearance does not reset sign-in or pairing.

Dark colours cover native screens, cards, lists, fields, dialogs and system bars. PDF document pages retain their original print colours. Windows does not need an update for this feature.

This remains a preview APK. Check its SIGNING-REPORT.txt before installing: a different signing certificate requires an additional Android Google OAuth client for package in.tallybridge.app and may require reinstalling and pairing the phone again. Keep the existing Web OAuth client ID and Cloudflare setup.
