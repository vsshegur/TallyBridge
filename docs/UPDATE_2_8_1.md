# TallyBridge 2.8.1 — scrolling fix for the PC control center

## Install

Close TallyBridge from its Windows tray menu and install `TallyBridge-2.8.1-Setup.exe` over the existing one. Settings, companies, phone pairing and the InvoiceTotally connection are kept. The phone app is unchanged (still 2.8.0), so there is nothing to install on the phone.

## Fixed

- **Everything can be reached on smaller screens.** On a laptop screen, or when the window was not maximised, the lower menu items and the bottom of long pages could not be scrolled to. Now the left menu and the page scroll on their own, with the mouse wheel or the scrollbar, and the version line stays at the bottom of the menu.
- Each page now opens at the top, and the menu keeps the selected item in view.
- In a very narrow window the menu sits above the page and the whole window scrolls.

See [2.8.0](UPDATE_2_8_0.md) for the GSTR-2B check and the other 2.8 changes.
