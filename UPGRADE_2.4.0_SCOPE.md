# TallyBridge 2.4.0 scope

This release intentionally implements only the selected upgrade areas:

- permanent Android signing identity diagnostics and verified in-app updater
- Customer 360 upgrades
- Quick Order
- Voice Order with review-before-save
- Today workspace
- smart alerts
- payment/outstanding follow-ups
- global search
- Company Health
- Diagnostics 2.0
- safe Tally performance monitoring
- organized Android and Windows navigation
- adaptive Sales/Proforma PDF layout for short invoices so bank details remain on the first page when they fit cleanly

Tally access remains read-only. Orders and follow-ups are TallyBridge-local and never create/alter/delete a Tally voucher.
